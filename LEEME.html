Guía del evaluador · Windows x64

De la descarga
a la primera factura.

Un paquete local con la aplicación compilada, SQL Server y toda la documentación. Siga estos pasos para evaluar la solución.

01Descargue y compruebe

Desde SharePoint, descargue el ZIP completo y su SHA256SUMS.txt externo. En PowerShell, calcule el SHA-256 del ZIP y compare el valor completo con el publicado.

Get-FileHash -LiteralPath '.\Aplicacion-<version>.zip' -Algorithm SHA256

Reemplace <version> por el nombre recibido. Verifique también que la carpeta pertenece al remitente esperado.

02Prepare el equipo

Abra Docker Desktop en modo Linux. Se requiere Windows x64 con virtualización y Compose v2. La primera configuración de WSL 2 puede requerir un reinicio.

Reserve memoria y espacio para Docker y SQL; recomendamos 6 GiB disponibles para Docker y 10 GiB de disco. La primera ejecución necesita internet para descargar imágenes oficiales.

El paquete no instala Docker ni modifica políticas de seguridad del equipo. No necesita Node, Visual Studio ni SDK de .NET para ejecutarlo.

03Extraiga toda la carpeta

Después de verificar el ZIP, abra Propiedades → Desbloquear si Windows muestra esa opción. Extraiga a una carpeta local, por ejemplo C:\Evaluacion\Facturacion, fuera de OneDrive o de carpetas sincronizadas.

Mantenga juntos app/, database/, scripts/, compose.yaml y los demás archivos. No ejecute desde la vista previa del ZIP.

04Inicie la aplicación

Haga doble clic en iniciar.cmd. El proceso comprueba la entrega, prepara credenciales locales únicas, inicia SQL, crea el esquema y abre el navegador.

.\iniciar.cmd

La dirección es http://127.0.0.1:5080. La primera descarga puede tardar. El comando informa cuando la aplicación está lista.

Esta guía no detecta Docker ni ejecuta comandos. Copiar sólo coloca texto en el portapapeles.

05Evalúe y conserve sus datos

Cree una factura, revise el descuento desde 500000, guarde y consulte su número. Después pruebe crear y buscar una cuenta simulada.

Las facturas se guardan en SQL. Accounts simuladas se conservan en memoria durante la sesión del proceso; no se realizan operaciones en Novasoft real desde este paquete.

.\detener.cmd

Al volver a ejecutar iniciar.cmd, las facturas siguen disponibles. Conserve local.env de forma privada y no elimine el volumen SQL.

Ejecución en su equipo

Qué contiene

  • Angular y .NET compilados.
  • SQL Server aislado en Docker.
  • Fuentes, tests y decisiones técnicas.
  • Backup vacío migrado y verificado en CI.
  • Inventario SBOM y checksums.

El ZIP final sólo se genera tras superar los controles de CI. Una carpeta de fuentes no equivale a ese paquete.

Comandos útiles

diagnosticar.cmd
Estado e integridad sin mostrar secretos.

backup.cmd
Crea un backup de sus datos.

restaurar.cmd
Restaura en una base nueva sin reemplazar la activa.

Los backups personales y local.env no se deben cargar como parte de la entrega original.

Si algo no inicia

  • Confirme Docker abierto y motor Linux.
  • Revise que 5080 esté libre.
  • Compruebe memoria y espacio.
  • Ejecute diagnosticar.cmd.

Una política corporativa puede impedir ejecutar scripts. Mantenga sus controles y use el procedimiento aprobado por su administrador.

Guía autocontenida: no carga fuentes, librerías ni imágenes de internet. Las animaciones respetan la preferencia de movimiento reducido.
